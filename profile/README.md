# CINA Labs

## Institutional On-Chain Infrastructure

CINA Labs is building deterministic settlement, entitlement, NAV reconciliation, and asset-liability accounting infrastructure for tokenized real-world assets.

CINA Main Protocol v4.2 has completed reproducible implementation verification and full scripted Sepolia acceptance. Token Studio supports institutional fund operations, while the CINA DApp provides user access to supported on-chain flows.

We are opening the protocol to community engineers interested in:

- Solidity / EVM protocol engineering
- DeFi and ERC-4626
- RWA and tokenized funds
- On-chain accounting and settlement
- Oracle, NAV, and pricing mechanisms
- Smart contract security, Foundry, fuzzing, and invariant testing
- Protocol operations and automation

This is financial-infrastructure engineering, not a generic Web3 frontend role.

## Live Platforms

- **Token Studio**: institutional fund operations, governance, KYC and fund-eligibility workflows, NAV operations, and settlement administration. [Open Token Studio](https://admin.setsyn.com)
- **CINA DApp**: user-facing access to supported CINA on-chain flows. [Open CINA DApp](https://wrmb-dapp.dev.isecsp.cn)
